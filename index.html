    6. UKURAN & CSS UNITS

    Ukuran dapat memakai unit absolut seperti px atau unit relatif seperti %, rem, dan vw.

    px vs %

    Pixel tetap; persentase mengikuti lebar parent.

    200px
    50%
    width: 200px; /* dibandingkan */ width: 50%;

    rem

    Ukuran font relatif pada font-size root (umumnya 16px).

    1rem1.5rem2rem
    font-size: 1rem; /* 1.5rem; 2rem */

    em vs rem

    em mengikuti ukuran font parent; rem mengikuti ukuran font root.

    Parent 20px 1em1rem
    font-size: 1em; /* vs 1rem */

    ch

    Unit ch kira-kira selebar karakter "0", berguna untuk membatasi panjang baris.

    Baris ini dibatasi dengan satuan ch agar panjangnya mudah dibaca.
    max-width: 28ch;

    vh

    1vh adalah 1% tinggi viewport; kotak memakai setengah tinggi viewport dengan batas.

    50vh
    height: 50vh; min-height: 100px; max-height: 240px;

    calc()

    calc() menggabungkan nilai dan unit untuk ukuran yang dihitung.

    width: calc(100% - 40px)
    width: calc(100% - 40px);

    vw

    1vw adalah 1% lebar viewport. Ukuran ini memakai 30vw lalu dibatasi min dan max agar tetap terbaca.

    30vw (dibatasi min/max)
    width: min(80%, 30vw); min-width: 130px; max-width: 260px;

    aspect-ratio

    Menjaga rasio lebar dan tinggi elemen.

    16:9
    aspect-ratio: 16 / 9;

    min-width & max-width

    Menentukan batas minimum dan maksimum lebar elemen.

    min-width: 120px; max-width: 220px;
    width: 100%; min-width: 120px; max-width: 220px;
